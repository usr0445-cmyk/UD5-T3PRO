# UD5-T3PRO

La actividad de figuras consiste en crear una jerarquía donde existe una figura geométrica base y varias figuras específicas que heredan de ella. Cada figura implementa su propia forma de calcular el área y el perímetro, demostrando cómo diferentes clases pueden compartir una estructura común pero comportarse de manera distinta. En la parte final se crean varias figuras y se muestran sus resultados para comprobar que cada una aplica correctamente sus fórmulas.

La actividad de vehículos consiste en crear una estructura de herencia donde se define un vehículo genérico y luego un coche de combustión que amplía ese comportamiento. Se trabaja con atributos comunes, métodos que deben ser implementados por las clases hijas y la simulación del funcionamiento real de un coche: arrancar, moverse, consumir combustible y detenerse. Finalmente, se prueba todo en un programa principal donde se crea un coche, se realizan acciones sobre él y se observa cómo cambia su estado según el combustible disponible y si el motor está encendido o apagado.
