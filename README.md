# UD5-T3PRO
La práctica consiste en crear una estructura básica de herencia donde se define un vehículo genérico y luego un coche de combustión que amplía ese comportamiento. Se trabaja con atributos comunes, métodos que deben ser implementados por las clases hijas y la simulación del funcionamiento real de un coche: arrancar, moverse, consumir combustible y detenerse. 

Finalmente, se prueba todo en un programa principal donde se crea un coche, se realizan acciones sobre él y se observa cómo cambia su estado según el combustible disponible y si el motor está encendido o apagado.
